# SITA

## Overview

As a Senior Technical Writer at SITA, I create and improve documentation for aviation technology products, working closely with product, engineering, and support teams.

Alongside technical writing, I work on documentation strategy, information architecture, governance, and AI adoption with a particular focus on making large documentation sets easier to manage, maintain, and scale.

## Key Projects

### AI Document Processing Engine
Co-created an AI-powered workflow to modernize documentation. The engine converts Word documents to Markdown, applies AI-assisted improvements, and recreates release-ready Word and Markdown output for a wider range of content and delivery needs.

**Impact:** Faster document modernisation, more consistent style, improved content quality, and reusable Markdown source content.

### MadCap Flare Administration
Managed all Flare related administration, template rebranding, migration, and platform maintenance across a large documentation estate.

**Impact:** Redesigned and modernized the Flare template for company rebranding and improved the PDF template.

### Documentation Quality and Team Growth
Supported the documentation function through quality improvement initiatives and writer onboarding, helping strengthen the technical writing team and improve delivery consistency. Redesigned toolkits, improved templates, and built a more scalable documentation operating model.

**Impact:** Better process maturity, stronger documentation standards, and improved team capability.
