# Sidero Sample Work & Deliverables

## Ericsson Network Manager Documentation Delivery

**Project Type:** Product documentation, enterprise software

### Overview

I managed documentation for Ericsson Network Manager in a DITA-based environment, supporting release-ready content aligned with sprint-based product delivery.

**Problem Solved:** Complex product documentation must keep pace with rapid change while staying accurate, structured, and easy to maintain.

**Solution Delivered:** I created and maintained documentation sets that supported release cycles and enabled product teams to ship confidently with the right documentation in place.

### Deliverables
- Small Integrated ENM user guides and reference material
- Release documentation and change notes
- Installation and configuration guides
- Troubleshooting and support documentation
- Administration and maintenance documentation
- Documentation builds and release artifacts

### Tools & Technologies
DITA CMS, XML authoring, MadCap Flare, documentation automation

### Impact
- Consistent sprint delivery
- No documentation blockers
- Reusable modular content
- Better release readiness

## DITA CMS Web Editor Rollout

**Project Type:** Tool adoption, training and enablement

### Overview

This work focused on rolling out a DITA CMS web editor to broader teams, improving authoring efficiency and making structured authoring more accessible across multiple teams.

**Problem Solved:** Authoring tools were too rigid or too dependent on specialist users, creating bottlenecks and reducing content velocity.

**Solution Delivered:** I supported adoption of the editor and created enablement resources that simplified usage and improved cross-team participation.

### Deliverables
- DITA XML authoring templates and examples
- Content reuse patterns and modular authoring guide
- Web editor training materials and tutorials
- Information architecture and topic structure documentation
- Best practices and style guide
- Writer enablement and adoption resources

### Tools & Technologies
DITA XML, DITA CMS, content reuse, modular design, training documentation

### Impact
- Faster content creation
- Improved collaboration
- Reduced tool friction
- Wider team participation in authoring
